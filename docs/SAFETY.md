# 安全与验证边界

- 本库不读取本地聊天数据库，不实现机器人登录，不加群、不发消息、不绕过受保护屏幕，不进行后台聊天采集。
- 宿主负责读取授权、上传授权、正确的消息来源、取消和UI生命周期。单纯传入true或不更新revision会让来源/授权校验失去实际意义。
- 默认客户端只接受HTTPS，不内置密钥或服务商回退。它不是模型价格白名单，无法证明模型免费；调用前由宿主确认费用和授权。硅基流动仅允许已核实免费的模型，禁止其全部DeepSeek型号及收费兜底；官方DeepSeek也需任务授权。
- 凭据过滤为启发式，不等于完整隐私防护。避免输入真实密钥、密码、第三方私人信息；不要把请求内容和原始错误写入日志。
- 知识点必须匹配原文，英文词按完整token边界过滤，普通词/碎片/嵌套概念被清理。此校验不能判定释义或专业概念一定正确。
- 提示词要求总结每项不超过180字，当前继承的解析器硬上限为600字符；分析解释提示400字、解析硬上限1200字符，回复提示150字、解析上限300字符。提示目标与硬拒绝阈值不同，不应宣称有更严格的程序保证。
- 总结引用只能指向所选消息，但有引用不代表内容与来源真正一致；未选上下文、完整历史、群成员身份和全部未读均不在保证范围内。
- `RequestGate.cancel`只能尽力取消，无法撤回已经发送的内容。宿主仍须使用请求ID避免晚到结果覆盖新界面。

## 验证范围

验证使用合成消息与内存HTTP替身，覆盖概念边界、重复消息、显式选择、来源引用、授权撤销、来源变化、取消、截断结果和失败不重试；默认演示注入合成返回值，不产生模型请求。

Android卡片只进行构建与Lint检查。本次未进行独立模块的手机交互验收、真实模型质量测试、长时间稳定性测试或多应用兼容验收。完整版此前的单设备记录不能替代此独立模块的集成验证。

公开源码不是生产可用或合规认证，项目尚未选择开源许可证。
